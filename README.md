# Dua Malik Portfolio
Plain HTML/CSS/JS. No install or build needed.

1. Open the folder in VS Code and run with the Live Server extension (or double-click index.html).
2. Your photo: save it as `assets/images/dua.jpg`.
3. Links and text: edit only `js/data.js`. Paste each LinkedIn post link into the `link` field of that project or certificate.
4. Real screenshots: open your live sites, take a screenshot of each, and save them in `assets/images/` as `skill.png`, `space.png`, `truck.png`, `carpool.png`. They are picked up automatically (the drawn mockups show until then).
5. GitHub: `git init`, `git add .`, `git commit -m "portfolio"`, create a repo, `git push`.
6. Vercel: Add New Project, import the repo, Framework Preset "Other", Deploy.
